INNOOpen 2026 · WEB

## 1. Смотрим бинарник

Перед нами бинарь без debug символов, так ещё и с русскими символами в принтф. Найдя функцию `main` изучаем её логику и видим два использования функций `scanf`:

```C
cost = __isoc99_scanf("%d",&inp);
...
iVar1 = __isoc99_scanf("%u",amount);
```

В первом случае у нас спрашивают какой товар мы хотим купить, во втором его количество

## 2. Изучаем типы данных

Как мы заметили, в первом случае у нас вводится `int`, а во втором `uint` (беззнаковый int, максимум - 4294967295). Дальше замечаем этот участок:

```C
uint all_cost;
...

all_cost = cost * amount[0];
if (balance < all_cost) {
    printf(...);
}
else {
    balance = balance - all_cost;
    ...
}
```

Программа умножает стоимость одного элемента на количество. При этом общая стоимость тоже имеет тип `uint`. Если результат умножения будет больше `MAX_UINT`, то возникнет переполнение переменной. Таким образом, можно подобрать такое количество пирожков чтобы их цена была меньше наших 50 монет

## 3. Подбираем пирожки

MAX_UINT = 4294967295 и цена флага 1000, значит нам нужно такое количество пирожков `n`, что `1000n mod (MAX_UINT + 1) <= 50`
Пишем простенький скрипт на питоне, который перебирает миллионы чисел

```python
maxu = 0xFFFFFFFF + 1

for i in range(1, 10**10):
    if (1000 * i) % maxu <= 50:
        print(i)
        break
```

И получаем ответ `42949673`
Вводим ответ и получаем флаг:

```

Сколько штук "Секретный пирожок"? > 42949673

Держите секретный пирожок, внутри записка: CTF{FAKE_FLAG_NOT_SOLVE_IT}
```
